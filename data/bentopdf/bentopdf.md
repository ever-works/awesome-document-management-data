## Overview

BentoPDF is a powerful, privacy-first, client-side PDF toolkit that allows users to manipulate, edit, merge, and process PDF files directly in their browser without uploading documents to a server.

## Features

- Client-side PDF processing (privacy-first)
- Edit, merge, and process PDF files
- Browser-based operation

## Deployment

Self-hosted via Docker
