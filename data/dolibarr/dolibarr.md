## Overview

Dolibarr is an open-source ERP and CRM software package for small and medium businesses, freelancers, and foundations, with built-in document management features.

## Features

- Document storage and versioning
- File access control and permissions
- Document categorization and tagging
- Integration with CRM, ERP, invoicing, and project modules
- Web-based interface
- Multi-user support with role-based access

## Deployment

Self-hosted; runs on PHP with MySQL, MariaDB, or PostgreSQL.
