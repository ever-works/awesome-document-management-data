## Overview

ownCloud is an open-source, self-hosted file sharing and collaboration platform for storing, syncing, and sharing files and documents on private infrastructure.

## Features

- File synchronization and sharing across desktop and mobile devices
- Web-based file manager with document preview
- Versioning and access control
- User and group management
- External storage support (S3, FTP, WebDAV, etc.)
- Encryption and security features
- Collaboration apps and plugins
- Integration with document editors

## Deployment

Self-hosted; supports LAMP stack and various Linux environments.
