## Overview

Stirling-PDF is a locally hosted web application that allows you to perform various operations on PDF files, such as merging, splitting, file conversions and OCR.

## Features

- PDF merging
- PDF splitting
- File conversion
- OCR
- Locally hosted

## Deployment

Self-hosted via Docker
