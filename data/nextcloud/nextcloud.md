## Overview

Nextcloud is an open-source, self-hosted file sharing and collaboration platform providing document management, file synchronization, and productivity capabilities.

## Features

- File synchronization and sharing across devices
- Document management with versioning and access control
- Integrated document editors (Collabora Online, ONLYOFFICE)
- Calendar, contacts, and task management apps
- User and group management with granular permissions
- External storage integration (S3, FTP, SFTP, WebDAV)
- End-to-end encryption option
- Extensive app ecosystem

## Deployment

Self-hosted; supports LAMP stack, Docker, and various Linux distributions.

## Pricing

Free and open source under the GNU Affero General Public License (AGPL); enterprise support and additional features available via paid subscriptions.
