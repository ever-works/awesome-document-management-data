## Overview

Zapier is an automation platform that connects 10,000+ apps to automate document workflows. It acts as an automation layer rather than a standalone document repository, enabling documents to move between the tools teams already use.

## Features

- Connects to 10,000+ apps for end-to-end document workflows
- AI automation where judgment is needed (e.g., extracting renewal dates, flagging unusual clauses)
- Visual editor for building automated workflows (Zaps)
- Automatic error detection and proposed fixes for broken Zaps
- AI agent integration with Claude, ChatGPT, Cursor, and other tools
- Centralized management of app access and Zap visibility

## Integrations

- Microsoft SharePoint
- Box

- Slack
- And 10,000+ other apps
