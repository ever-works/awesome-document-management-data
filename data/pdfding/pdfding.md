## Overview

PdfDing is a PDF manager, viewer and editor offering a seamless user experience on multiple devices. It is designed to be minimal, fast, and easy to set up using Docker.

## Features

- PDF management
- PDF viewing
- PDF editing
- Multi-device support
- Minimal and fast

## Deployment

Self-hosted via Docker
