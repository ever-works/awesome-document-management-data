## Overview

onPhase (formerly DocuPhase) helps businesses transform operations with automated document management and workflows. It features AI-powered data capture and document retrieval for extracting essential information from diverse documents.

## Features

- Powerful OCR capabilities for capturing information from paper documents
- Pre-built workflow automation to streamline document processes
- Built-in eSigning tool for digital signatures
- AI-powered data capture and document retrieval
- Document processing for older and diverse file types
