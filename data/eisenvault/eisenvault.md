## Overview

EisenVault is a document management platform with an extra focus on security. It features a robust encryption algorithm to keep documents safe and provides audit trail capabilities for compliance and security purposes.

## Features

- Robust encryption algorithm for document security
- High storage capacity for storing and sharing large files
- Easy to use after initial setup
- Audit trail for compliance and security
- Access control for restricting access to sensitive documents
- View, edit, and approve document permissions
