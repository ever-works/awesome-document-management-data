## Overview

SnapOtter is a suite of 200+ web tools for converting and editing images, videos, audio and PDFs, including a layer-based image editor, OCR, transcription, background removal and batch processing pipelines.

## Features

- 200+ web tools
- Image conversion and editing
- Video conversion
- Audio conversion
- PDF conversion and editing
- Layer-based image editor
- OCR
- Transcription
- Background removal
- Batch processing pipelines

## Deployment

Self-hosted via Docker
